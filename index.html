What is CAR

A runtime that never takes the AI’s word for it.

CAR is a program you install on your own computer that runs AI agents and looks after them: it keeps them alive in the background, restarts them when they crash, and stops to ask your permission before anything risky — it can even text you for the OK.

Its signature habit is proof: for coding jobs and goal runs it writes down up front what done must look like as real checks, then re-runs those checks itself and refuses to say finished until they actually pass — it never just takes the AI’s word for it.

The thinking can come from cloud models, local models, or agents like Claude Code; either way the work, the rules, and the receipts stay on your machine. We run our own fleet of agents on it every day — it’s the harness we trust them with.

Proof-of-done

The runtime re-runs real checks. Exit codes decide done — never the model’s self-report. The AI doesn’t get to grade its own work.

How it works

Four steps from install to proven work.

1

Install CAR

One installer puts the runtime and the car CLI on your machine. No cloud account required.

2

Start an agent

Agents run under supervision: they persist in the background and restart automatically when they crash.

3

Risky ops ask first

Anything risky routes through approval before it happens — CAR can even text you for the OK.

4

Checks decide done

Done is written down as real checks up front, and CAR re-runs them itself before it will say finished.

The thinking is rented from clouds and chat windows; the work itself — the files it changes, the rules it must obey, the evidence that it did what it claims — deserves to live somewhere you own.
